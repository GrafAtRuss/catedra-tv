# Модуль сайта Joomla 6

`mod_catedra_apps` читает [versions.xml](https://raw.githubusercontent.com/GrafAtRuss/catedra-tv/main/versions.xml) и показывает приложения карточками:

- название
- иконка и QR-код на скачивание
- краткое описание
- версия под названием

## Установка

1. Скачайте [mod_catedra_apps.zip](https://github.com/GrafAtRuss/catedra-tv/raw/main/joomla/mod_catedra_apps.zip).
2. В Joomla: Система → Установка → Загрузить и установить.
3. Система → Модули сайта → Создать → «Кафедра: приложения».
4. Поставьте модуль в нужную позицию и опубликуйте.

По умолчанию видны телефон, Android TV, Яндекс ТВ, Samsung и обе Авроры. Сборки RuStore в списке есть, но выключены: их можно отметить в поле «Выбранные приложения». Если снять все галочки, снова показываются эти шесть. Режим «Все из каталога» показывает всё, что есть в XML.

Если сменили адрес каталога, сохраните модуль и откройте его снова — список для галочек читается из XML при открытии настроек.

Список на сайте обновляется сам, по умолчанию раз в час. На GitHub файл обновляется при публикации релиза.
