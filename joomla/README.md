# Модуль сайта Joomla 6

`mod_appcatalog` — универсальный каталог. Он не привязан к одному проекту: в настройках указывается ссылка на XML, и модуль показывает то, что в этом файле.

Карточка: название, иконка, QR-код на скачивание, краткое описание. Скачивание открывается в новом окне. Пользовательское соглашение и политика конфиденциальности берутся из того же XML (они общие на весь каталог) и открываются во всплывающем окне.

Для «Кафедры» ссылка уже подставлена: [versions.xml](https://raw.githubusercontent.com/GrafAtRuss/catedra-tv/main/versions.xml). Её можно заменить на свой файл того же вида.

## Установка

1. Скачайте [mod_appcatalog.zip](https://github.com/GrafAtRuss/catedra-tv/raw/main/joomla/mod_appcatalog.zip).
2. В Joomla: Система → Установка → Загрузить и установить.
3. Система → Модули сайта → Создать → «Каталог приложений».
4. Проверьте ссылку на XML, число карточек в ряду, поставьте модуль в нужную позицию и опубликуйте.

Поле «Карточек в ряду» задаёт, сколько карточек стоит рядом. Они сужаются, чтобы поместиться, а неполный ряд выравнивается по центру.

«Сторонние ссылки» — карточки, которых нет в XML. Для каждой вручную указываются название, версия, иконка, ссылка на скачивание и краткое описание. Они встают в тот же ряд после приложений из каталога. «Комментарий над документами» выводится над кнопками соглашения и политики.

По умолчанию видны все приложения из файла. Чтобы оставить часть, выберите «Только выбранные» и отметьте нужные. Если сменили ссылку, сохраните модуль и откройте его снова — список для галочек читается из XML.

Список на сайте обновляется сам, по умолчанию раз в час.
