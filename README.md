# Кафедра 1.1.1

Приложение для трансляции мессы Римско-католического кафедрального собора Непорочного Зачатия Пресвятой Девы Марии в Москве.

- Эфир: https://catedra.ru/online (Kinescope)
- Расписание: https://catedra.ru/schedule, время московское
- Записи: канал прихода на YouTube
- Настройки: прокси (префикс `http://хост:порт` или параметр `url`), свой Invidious/Piped и запасная ссылка на эфир, в том числе `.m3u8`

## Samsung UE49N5500 (Tizen 4.0)

Нужен ForkTizenInstall 1.0.1. Телевизор и компьютер в одной сети.

1. На телевизоре откройте приложения Smart Hub и наберите 12345. Включите режим разработчика и укажите IP компьютера.
2. Распакуйте ForkTizenInstall 1.0.1 на Windows и положите `Catedra-1.1.1.wgt` в папку `apps`.
3. Установите виджет «Кафедра» по инструкции программы. Если пакет не подписан, подпишите его сертификатом разработчика — для ForkTizenInstall это обычный шаг.
4. Пульт: стрелки и OK, «Назад» возвращает. Красная, зелёная, жёлтая и синяя клавиши совпадают с цифрами 1–4.

## Android TV, YaOS и YaOS X

Один и тот же APK. Сервисы Google не нужны.

1. Разрешите установку неизвестных приложений для файлового менеджера или браузера: настройки, безопасность, «Неизвестные источники».
2. Скопируйте `Catedra-1.1.1.apk` на флешку и откройте его на телевизоре. Либо скачайте файл во встроенном браузере и подтвердите установку.
3. «Кафедра» появится в ряду приложений с баннером собора. На YaOS и YaOS X при необходимости закрепите её на главном экране из списка приложений.
4. При первом запуске система предложит добавить канал на домашний экран: прямой эфир и службы дня. Разрешите — строка останется на главной. Эфир и открытая запись попадают в «Смотреть далее».
5. Пульт: стрелки и OK, «Назад» возвращает. Play и Pause обрабатывает система. Кнопка Home во время эфира сворачивает картинку в угол, если телевизор это умеет. Поиск телевизора находит мессу и записи. Ссылка catedra.ru/online открывается в «Кафедре».

Обновление ставится поверх, если пакет подписан тем же ключом. Ключ подписи в этот репозиторий не входит.
