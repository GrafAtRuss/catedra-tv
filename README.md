# Кафедра 1.2.22

Приложение для трансляции мессы Римско-католического кафедрального собора Непорочного Зачатия Пресвятой Девы Марии в Москве.

- Эфир: https://catedra.ru/online (Kinescope)
- Расписание: https://catedra.ru/schedule, время московское
- Записи: канал прихода на YouTube
- Настройки: прокси (префикс `http://хост:порт` или параметр `url`), свой Invidious/Piped и запасная ссылка на эфир, в том числе `.m3u8`

Автор: Ермаков Алексей Сергеевич, alexey@ermakov-mail.ru

## Обновление

Приложение присылает уведомления о новой версии, начале трансляции и новых записях, даже если оно закрыто. На телефоне эфир продолжается, если заблокировать экран.

Телефон и Android TV при запуске проверяют последний релиз на GitHub. Если версия новее, приложение само скачивает пакет и открывает установку. Один раз нужно разрешить установку из «Кафедры». На Samsung виджет сообщит о новой версии: файл ставится через ForkTizenInstall, сам телевизор пакет не обновляет.

## Подпись

Телефон и Android TV подписаны одним ключом, `CN=Catedra`. Отпечаток SHA-256: `13EEC3286906EAE123E8D51BF156051A2747E27CEBFAF1B12F91AF90C9B4E2E7`. Схемы v1, v2 и v3. Этим же ключом подписаны предыдущие APK, обновление ставится поверх. Сам ключ в репозиторий не входит.

Виджет Samsung в архиве без подписи Tizen. Её ставит ForkTizenInstall сертификатом разработчика этого телевизора. Сертификат Samsung в репозиторий не кладётся: без него телевизор чужую подпись не примет.

Если трансляции нет, на месте плеера показывается объявление «Сейчас трансляции нет» и ближайшая служба. Плеер появляется сам, когда эфир начинается.

## Телефон и планшет

Файл `Catedra-Phone-1.2.22.apk`. Портрет и альбомная ориентация, управление пальцем. Сервисы Google не нужны. Это отдельное приложение, его можно ставить рядом с версией для телевизора.

1. Скачайте APK на телефон или передайте его через мессенджер, облако или флешку.
2. Откройте файл. Если система спросит, разрешите установку из этого источника.
3. На рабочем столе появится «Кафедра». «Назад» возвращает на главную, с главной закрывает приложение.
4. Во время эфира на Android 8 и новее можно свернуть приложение: картинка уходит в угол. Ссылка catedra.ru/online открывается в «Кафедре».

## Samsung UE49N5500 (Tizen 4.0)

Нужен ForkTizenInstall 1.0.1. Телевизор и компьютер в одной сети.

1. На телевизоре откройте приложения Smart Hub и наберите 12345. Включите режим разработчика и укажите IP компьютера.
2. Распакуйте ForkTizenInstall 1.0.1 на Windows и положите `Catedra-TV-1.2.22.wgt` в папку `apps`.
3. Установите виджет «Кафедра» по инструкции программы. Если пакет не подписан, подпишите его сертификатом разработчика.
4. Пульт: стрелки и OK, «Назад» возвращает. Цветные клавиши совпадают с цифрами 1–4. Цифра 5 или кнопка на плеере включает полный экран, «Назад» выходит из него.

## Android TV, YaOS и YaOS X

Один и тот же APK `Catedra-TV-1.2.22.apk`. Сервисы Google не нужны.

1. Разрешите установку неизвестных приложений для файлового менеджера или браузера.
2. Скопируйте APK на флешку и откройте его на телевизоре.
3. «Кафедра» появится в ряду приложений с баннером собора. На YaOS и YaOS X при необходимости закрепите её на главном экране.
4. При первом запуске система предложит добавить канал на домашний экран. Эфир попадает в «Смотреть далее». Кнопка Home во время эфира сворачивает картинку в угол, если телевизор это умеет.

Обновление телевизионного APK ставится поверх, если пакет подписан тем же ключом. Ключ подписи в этот репозиторий не входит.
